Tandem Task Manager

Shared boards for small teams. Owners run the workspace, members move the work, and everyone sees updates live.

  • Role-based access control (owner and member) across workspaces, boards and tasks.
  • JWT authentication with permission-scoped APIs.
  • Boards with To do, In progress and Done columns, task priority, due dates and assignees.
  • Real-time updates with Socket.io, and a one-click demo account.

Ledgerly Expense Tracker

A multi-tenant SaaS where every team gets a private workspace for expenses, with live spending insights and subscription billing.

  • Multi-tenant architecture that isolates each organization's expenses inside a shared database.
  • Stripe subscription billing with webhook handling for payment success, payment failure and cancellation, plus a built-in event simulator for demos.
  • Dashboard with a six-month spending chart and category breakdown.
  • Expense search, category filter, CSV export and team seats.
